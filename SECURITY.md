# Security Policy

## Supported Versions

The following table lists which versions of this project currently receive security updates:

| Version | Supported          |
| ------- | ------------------ |
| 5.1.x   | Yes                |
| 5.0.x   | No                 |
| 4.0.x   | Yes                |
| < 4.0   | No                 |

Please update to a supported version to ensure you receive security patches and updates.

---

## Reporting a Vulnerability

If you discover a security vulnerability, please report it responsibly.

### How to Report

- Email: [security@example.com](mailto:security@example.com)
- GitHub Issues: Please do not use GitHub issues to report security problems. Use the email above instead.
- Response Time: You can expect a response within 3–5 business days.

### What to Include

When reporting a vulnerability, please include:

- A clear description of the issue
- Steps to reproduce (if possible)
- Impact assessment (what could go wrong)
- Any logs or screenshots (if helpful)

---

## What Happens Next

1. We will investigate the issue and confirm receipt of your report.
2. If valid, a fix will be developed privately.
3. You will be notified once the issue is resolved and a patch is released.

We appreciate responsible disclosure and thank you for helping us keep the project secure.
